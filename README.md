# 🌤️ WeatherNexus

**[▶ Live demo](https://weather-app-self-projects4.vercel.app)**

> A beautiful, feature-rich weather application with multiple themes and real-time weather data.

## ✨ Features

### 🎨 5 Beautiful Themes
- **Nature** 🌱 - Fresh green gradient theme
- **Dark** 🌙 - Elegant dark mode  
- **Gaming** 🎮 - Vibrant gaming-inspired theme
- **Sunset** 🌇 - Warm sunset colors
- **Ocean** 🌊 - Cool ocean blue theme

### 🌡️ Weather Data
- **Real-time Conditions**: Current weather with feels-like temperature
- **5-Day Forecast**: Detailed daily predictions
- **Hourly Forecast**: 12-hour weather predictions
- **Advanced Metrics**: UV index, air quality, pressure, humidity
- **Astronomy Data**: Sunrise, sunset, moon phase

### 🔧 Functionality
- **Location Services**: GPS-based automatic detection
- **Unit Toggle**: Celsius/Fahrenheit switching
- **Search History**: Remembers last searched location
- **Responsive Design**: Works on all devices

## 🚀 Quick Start

1. **Download all three files:**
   - `index.html`
   - `style.css` 
   - `app.js`

2. **Open `index.html`** in any modern browser

3. **Start using:**
   - Search for any city
   - Use your current location
   - Switch themes and units

## 📱 Usage

| Action | How To |
|--------|---------|
| **Search City** | Type name + Enter/Search button |
| **Use Location** | Click 📍 button |
| **Change Theme** | Select from dropdown menu |
| **Switch Units** | Click °F/°C button |

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Weather Data**: WeatherAPI.com
- **Icons**: Weather Icons & Font Awesome
- **Storage**: Local Storage for preferences
- **Styling**: CSS Grid, Flexbox, Glass Morphism

## 🔑 API Information

- **Provider**: WeatherAPI.com
- **Key**: Included and ready to use
- **Data**: Real-time weather, forecasts, astronomy
- **Security**: All calls via HTTPS

## 🔒 Privacy

- No user data tracking
- Location data used only for weather services
- All processing happens locally in browser
- Preferences stored in local storage only
